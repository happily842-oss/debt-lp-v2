スマホのGoogle広告アプリより操作しやすい、シンプルな管理画面です。キャンペーンの一覧表示・停止・再開ができます。

Googleでログイン

初回セットアップが必要です

Vercelの環境変数に以下を設定してください。

  1. GOOGLE_ADS_CLIENT_ID / GOOGLE_ADS_CLIENT_SECRET
  2. GOOGLE_ADS_DEVELOPER_TOKEN
  3. GOOGLE_ADS_CUSTOMER_ID（広告アカウントID）
  4. SESSION_SECRET（ランダム文字列）
  5. APP_URL（例: https://your-domain.vercel.app）

Google Cloud ConsoleでOAuthクライアントを作成し、リダイレクトURIに {APP_URL}/api/auth/callback を追加してください。
